Самые частые формулировки
Файл: CSV, JSON или XLSX. Колонки (рус/англ алиасы): дата, вопрос, категория, время_ответа (с), оценка (правильный / частично / вода / ошибка), дефект. Обязательны только «вопрос» и «время_ответа»; остальное - опционально, блоки без данных скрываются. Всё считается локально в браузере, файл никуда не отправляется.
